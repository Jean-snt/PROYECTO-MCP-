4. MODELOS DE DATOS DETALLADOS
================================================================================

4.1 MODELO ITEM (inventory_item)
---------------------------------
Propósito: Representa los medicamentos/productos en el inventario

Campos:
- sku (CharField, max_length=100, unique=True)
  * Código único de identificación del producto
  * Campo obligatorio y único en toda la base de datos

- name (CharField, max_length=200)
  * Nombre del medicamento/producto
  * Campo obligatorio

- type (CharField, max_length=20, choices)
  * Tipo de medicamento con opciones predefinidas:
    - 'pastilla': Pastilla
    - 'jarabe': Jarabe
    - 'inyectable': Inyectable

- disease_category (CharField, max_length=100)
  * Categoría de enfermedad que trata el medicamento
  * Permite clasificación por tipo de dolencia

- price (DecimalField, max_digits=10, decimal_places=2)
  * Precio unitario del producto
  * Formato: hasta 8 dígitos enteros y 2 decimales

- stock (IntegerField)
  * Cantidad disponible en inventario
  * Número entero positivo o negativo

- version (IntegerField, default=1)
  * Control de versiones del producto
  * Valor por defecto: 1

Método __str__: Retorna "sku - name"

4.2 MODELO ORDER (inventory_order)
----------------------------------
Propósito: Representa las órdenes de compra/venta

Campos:
- code (CharField, max_length=100, unique=True)
  * Código único de la orden
  * Campo obligatorio y único

- status (CharField, max_length=20, choices)
  * Estado de la orden con opciones:
    - 'NEW': New (Nueva)
    - 'PAID': Paid (Pagada)
    - 'CANCELLED': Cancelled (Cancelada)
    - 'ROLLEDBACK': Rolled Back (Revertida)

- total (DecimalField, max_digits=10, decimal_places=2)
  * Monto total de la orden
  * Formato: hasta 8 dígitos enteros y 2 decimales

Método __str__: Retorna "Order code - status"

4.3 MODELO ORDERLINE (inventory_orderline)
------------------------------------------
Propósito: Representa las líneas individuales de cada orden

Campos:
- order (ForeignKey to Order, on_delete=CASCADE)
  * Relación con el modelo Order
  * Eliminación en cascada: si se elimina la orden, se eliminan sus líneas

- item (ForeignKey to Item, on_delete=CASCADE)
  * Relación con el modelo Item
  * Eliminación en cascada: si se elimina el item, se eliminan sus líneas

- quantity (IntegerField)
  * Cantidad del producto en esta línea de orden
  * Número entero

- unit_price (DecimalField, max_digits=10, decimal_places=2)
  * Precio unitario del producto en el momento de la orden
  * Puede diferir del precio actual del Item

- line_total (DecimalField, max_digits=10, decimal_places=2)
  * Total de esta línea (quantity * unit_price)
  * Calculado y almacenado

Método __str__: Retorna "order.code - item.name x quantity"
